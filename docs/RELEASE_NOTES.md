# MUSE 1.0.0 · 桌面跳舞少女

MUSE 是个会跟着音乐跳舞的桌面少女。选一首电脑里的歌就能看她跳，歌曲放完还会鞠躬。
想边做事边听歌，点一下缩小，只留下少女在桌面上跳，挡住东西时可以拖到旁边。

## 这一版有什么

- 完整 3D 舞台，浅色 / 深色外观，三组配色和随音乐变化的灯光。
- 透明、无边框、置顶的迷你模式，只留下少女；切换时继续播放。
- 本地音乐、麦克风输入和内置 120 BPM 试听节奏。
- 23 个动画片段，包含舞蹈、空闲、过渡及歌曲结束时的鞠躬致敬。
- 自动编舞、BPM 调整、点击打拍和节奏偏移微调。
- 白底 App 图标，增加人物四周留白。

## 下载与开始

下载附件 `MUSE_1.0.0_aarch64.dmg`，打开后将 MUSE 拖入 Applications。
此包面向 **Apple Silicon Mac（M 系列芯片）**，大小约 15 MB；配置的最低系统为 macOS 12.0。

打开后选择「播放本地音乐」或「试听律动」。缩小按钮进入迷你模式；拖动少女可移动，双击、右键或按 Esc 恢复舞台。
macOS 菜单 **Stage → Restore** 也可以恢复，快捷键 **⌘⇧M**。

## 已知限制

- 当前包使用临时签名，尚未经过 Apple 公证，系统可能限制首次打开。
- Intel Mac、Windows 和 Linux 尚未提供经过验证的安装包，也未逐个验证 macOS 系统版本。
- 自动拍速识别可能出现半速、倍速或偏移，可使用手动节奏控制修正。
- 麦克风听取环境声音，不直接捕获系统音频；实机麦克风录音仍需进一步验证。

音频分析与动画在本地完成，不需要账号或 API Key。随包附有 `SHA256SUMS.txt`，可用于核对下载完整性。
